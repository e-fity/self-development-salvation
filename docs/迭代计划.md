# 迭代计划：R11–R18（M1.5 → 可下载竖切片）

> 版本 0.3 计划，2026-11-19 制定。
> 基线：0.2.0 灰盒 M1，起点 HEAD `102def8`（18 个提交），106 条冒烟、24 项真窗口自动验收、`check.py --godot` 15/15、GitHub Actions 绿。
> 进度：R11 已于 2026-11-19 完成（134 条冒烟、25 项自动验收）；R12/R13 同日完成（144 条冒烟、36 项自动验收、9 张截图）；R14 首局试玩已进行（B 评价 2:30 / 受伤 47 / 连击 14），据此补了 HUD 常驻键位提示（147 条冒烟）；R15 手感部分提前完成（收招可移动，150 条冒烟）；2026-11-20 追加启动页（雨幕 + 按任意键进入，153 条冒烟）；其余待排。

## 0. 目标与非目标

本周期只做三件闭环的事：

1. **逻辑闭环**：检查点自动存档 + 死亡重试，对齐 PRD 验收第 7、10 条。
2. **观感闭环**：L 逆鳞 / I 零点 / 闪避有可辨识的视觉反馈，不再只有伤害数字。
3. **发行闭环**：Windows 可执行包 + CI 自动构建，别人点开就能下载试玩。

明确不做：手柄支持、`strings.csv` 本地化、`AnimatedSprite2D` 动画、商店/掉落、联机、Boss 新招式。这些等美术与设备到位再说。

## 2. 任务卡

### R11 检查点自动存档（11-20 ~ 11-23）✅ 已完成 2026-11-19

- **范围**：`game/autoload/save_system.gd`、`game/scenes/levels/level.gd`、`game/scenes/ui/title.gd`、`game/tests/smoke_test.gd`。
- **做什么**：存档 schema 升到 v2，新增 `progress{checkpoint:int, shrine_taken:bool}`；过检查点且档位变化时写盘；神龛只回满一次并落盘；标题页「继续」读档后从该检查点开始，而不是从 0 开始；v1 旧档迁移时补默认值。
- **完成标准**：状态不变时不重复写盘；读档恢复位置与神龛状态；旧档可读；主档损坏仍能从 `save.bak` 恢复。
- **检测**：冒烟 +28（写档时机、重载恢复、神龛只回一次、v1 迁移、坏档回退、无档时「继续」保持灰、真实关卡从存档继续）；`check.py --godot` 15/15；手动删档重进看是否从检查点开始。
- **风险**：schema 变更破坏旧档 → 必须写迁移测试 + 保留 bak 回退。

### R12 战斗反馈补完（11-24）✅ 已完成 2026-11-19

- **范围**：`game/scenes/player/player.gd`、`game/data/player.json`、`game/autoload/game_data.gd`、`game/tests/auto_accept.gd`。
- **做什么**：逆鳞 = 以玩家为圆心的环形冲击波（Line2D 圆环 tween 扩大淡出）；零点 = 全屏横向刀光（Polygon2D 白条 + 一次闪白）；闪避 = 3 帧残影（复用 Sprite2D 副本，预建节点池，禁止运行时 `new`）；命中顿帧按技能配置分级（逆鳞轻、零点重）。
- **完成标准**：三个技能各自有可截图的视觉帧；特效不遮挡 HUD；每帧零分配（节点池）。
- **检测**：自动验收 +11 断言（环/横斩可见、播完隐藏、残影池 3 个可见）+2 张截图（08 残影 / 09 横斩）；人工看图确认；`check.py --godot` 15/15。
- **风险**：全屏刀光盖住 Boss 血条 → z_index 限制在 50 以下并截图核对。

### R13 重试循环（11-25）✅ 已完成 2026-11-19

## 4. 审查机制

### 4.1 分支与提交

- 每个迭代一个分支：`iter/r11-checkpoint`、`iter/r12-feedback`……
- 完成后 `git diff main...HEAD` 自审一遍，再合回 `main`；远端可用时开 PR 走同一份清单。
- 提交用 Conventional Commits（`feat|fix|test|docs|chore`），提交正文写本次跑过的检测命令与结果。

### 4.2 审查清单（每迭代必勾）

1. diff 只含本迭代范围内的文件，没有顺手重构。
2. 新增测试先失败、后通过（红→绿），不是事后补的。
3. 新增配置项有默认表同值同步（规约 DATA-6）。
4. 每帧路径无 `new` / `load` / 文件 IO / 全树遍历（规约 GD-8）。
5. 新输入按工程规范 §8 四步登记。
6. 文案无「L/I 未实现」之类过期承诺。
7. 存档 schema 变更带版本迁移与 bak 回退测试。
8. README / 架构 / 审查报告 / 规约里的数字与命令同步。
9. `check.py --godot` 15/15。
10. level / title 场景 exit 0、无 SCRIPT ERROR。
11. 自动验收截图已人工看过，没有遮挡与穿帮。
12. 有回退路径（revert 提交或兼容开关）。

### 4.3 审查报告更新规则

每迭代结束在 `docs/代码审查报告.md` 增加一节 `Rn 表`，并同步：

- §1 基线条数（冒烟 / 自动验收 / 门禁）。
- §9 文件清单行数（用 `python` 统计实际行数）。
- 新增问题按 P0–P3 分级；P0 立即停线，P1 本迭代内修，P2 记录并排期。

### 4.4 出口标准

一个迭代只有同时满足下列条件才算完成：L0–L3 全绿、审查清单全勾、文档已同步、提交已推送、CI 绿。任一不满足则顺延，不进入下一迭代。
